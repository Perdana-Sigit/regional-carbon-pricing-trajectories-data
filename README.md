# regional-carbon-pricing-trajectories-data
Processed analysis data supporting the manuscript on regional economic trajectories under carbon pricing.
Carbon Transition
This repository contains the processed analysis data and model outputs supporting the manuscript.
The data cover 242 European NUTS-2 regions and include regional economic impacts, trajectory classifications, structural indicators, fossil-fuel specialisation measures, and renewable-energy potential variables used in the analysis.
The construction of the data and underlying sources are documented in the manuscript and Supplementary Material.
Authors: Sigit Perdana, Fang-Hsuan Chen, Marc Vielle.
